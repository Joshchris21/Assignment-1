## 🚀 Getting Started

### Prerequisites
- Web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code, Sublime Text, etc.)
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Replace Images** in the `assets/` folder with actual photos
4. **Customize Content** as needed for your specific facility


## 🎨 Customization

### Colors
The website uses CSS custom properties for easy color customization:
```css
:root {
    --primary-color: #2c5530;    /* Deep Forest Green */
    --secondary-color: #8b9d3a;  /* Olive Gold */
    --accent-color: #d4af37;     /* Gold */
    --warm-beige: #f5f1e8;       /* Warm Beige */
    --cream: #faf8f3;            /* Cream */
}
```

### Content
- Update contact information in the HTML
- Modify service descriptions and hours
- Replace placeholder images with actual photos
- Customize social media links

### Google Maps
Replace the embedded map with your actual location coordinates:
1. Go to [Google Maps](https://maps.google.com)
2. Search for your location
3. Click "Share" → "Embed a map"
4. Copy the iframe code and replace it in the HTML
