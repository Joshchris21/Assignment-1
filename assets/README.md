## Image Guidelines

1. **Quality**: All images should be high resolution and professionally taken
2. **Lighting**: Bright, welcoming lighting that shows the luxury nature of the facility
3. **People**: Include diverse groups of people enjoying the facilities (with proper permissions)
4. **Branding**: Ensure all images reflect the luxury, family-friendly brand of Magnolia
5. **Optimization**: Compress images for web while maintaining quality

## Recommended Image Sources

1. **Professional Photography**: Hire a professional photographer to capture the actual facility
2. **Stock Photography**: Use high-quality stock photos that match the facility's aesthetic
3. **Unsplash/Pexels**: Free high-quality images (ensure proper licensing)

## Color Scheme for Images

- Deep Forest Green (#2c5530)
- Olive Gold (#8b9d3a)
- Gold Accent (#d4af37)
- Warm, natural lighting
- Earth tones and luxury aesthetics

## Technical Specifications

- **Format**: JPG for photos, PNG for logos/graphics
- **Resolution**: Minimum 72 DPI for web
- **Compression**: Optimize for web (aim for under 500KB per image)
- **Alt Text**: Each image should have descriptive alt text for accessibility
